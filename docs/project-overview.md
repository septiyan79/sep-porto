## Tujuan

Website portfolio pribadi untuk menampilkan profil, keahlian teknis, dan proyek-proyek yang telah dikerjakan oleh Septiyan E.P., seorang Fullstack Web Developer dengan 5+ tahun pengalaman. Target audiens: calon klien, recruiter, atau kolaborator.

## Fitur Utama

### 1. Hero Section
Kartu utama dengan:
- Indikator "Available for projects" (animasi ping emerald)
- Nama dengan efek gradient (blue → emerald → cyan)
- Badge profesional: role, stack, mindset
- Bio teks (5+ tahun pengalaman, React/Next.js/Firebase/PHP)
- Kartu lokasi (Jakarta, UTC+7)
- Kutipan motivasional
- Tombol "Let's Talk" + social links (GitHub, LinkedIn, WhatsApp)

### 2. Tech Stack Section
Menampilkan keahlian teknis dalam 4 kategori:
- Frontend Skills (12 item)
- Backend Skills (11 item)
- Tools & Environment (8 item)
- Engineering Practices (5 item)

### 3. Projects Section
Showcase 8 proyek dengan:
- Kartu proyek dengan gradient warna unik tiap proyek
- Hover animation (lift -5px)
- Tombol link (GitHub/GitLab/Live Demo) muncul saat hover
- Tombol "View" membuka modal detail
- Status proyek (Active Dev / Complete)

### 4. Professional Profile Section
3 kartu paralel:
- **What I Bring** — keahlian yang ditawarkan
- **Professional Strength** — kekuatan profesional
- **Career Objective** — target karir saat ini

### 5. Navigation Sidebar (Desktop Only)
Sidebar fixed di kiri layar, hanya muncul di layar `lg:` ke atas:
- Navigasi ke Hero, Projects, Professional Profile
- Smooth scroll dengan tooltip hover

### 6. Ambient Background
Dua efek blur gradient (purple & blue) sebagai background dekoratif.

### 7. Footer
Copyright dan link GitHub.
